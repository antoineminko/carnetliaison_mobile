Le dossier appointments (qui signifie "rendez-vous" en anglais) sert à gérer toutes les rencontres et réunions entre les parents et les professeurs dans votre application.

Concrètement, c'est ce module qui permet de :

Lister les rendez-vous (En attente, À venir, Historique).
Prendre une décision : Un professeur ou un parent peut accepter, refuser, ou annuler un rendez-vous.
Proposer un report : Si la date ne convient pas, on peut proposer un nouveau jour et une nouvelle heure (ce que l'on vient de corriger ensemble).
Gérer les différents modes de rencontre :
En présentiel (à l'école)
Appel vocal (téléphone)
Appel vidéo (avec un bouton pour rejoindre directement la visioconférence)
